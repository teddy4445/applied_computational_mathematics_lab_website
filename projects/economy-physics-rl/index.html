About the project

What this project is about

Using reinforcement learning and ideas from physics to model and control microeconomic processes from data.

This project studies microeconomic processes through the lens of physical dynamical systems and uses reinforcement learning to learn and steer them from data. It ran mainly as Master's research at the Department of Computing, Jönköping University: Mahmut Osmanovic and Isac Paulsson worked on data-driven modeling of microeconomic processes as physical processes via reinforcement learning, and Lukas Toral studied a teacher-student architecture in which pre-trained large language models speed up the convergence of reinforcement-learning agents. The project builds on the lab's earlier computational-economy work, such as a microfounded tax-revenue forecast model and a benchmark of biologically-inspired automatic machine learning on economic tasks.

Key outcomes

  • Master's theses (Jönköping University, 2026) on reinforcement-learning models of microeconomic processes built on physical-process analogies
  • A teacher-student approach in which pre-trained large language models speed up reinforcement-learning convergence (Master's thesis, 2025)
  • A direct line to the lab's published computational-economy work on tax-revenue forecasting and automatic machine learning for economic tasks

Timeline

How the project developed.

    Groundwork

    The lab published a microfounded tax-revenue forecast model and benchmarked biologically-inspired automatic machine learning on economic tasks.

  2. 07/2024

    Project started

    The project took shape around reinforcement-learning control of economic processes using physically inspired models.

  3. 01/2025 - 07/2025

    LLM teacher, RL student

    Lukas Toral's Master's research used pre-trained large language models as teachers to speed up reinforcement learning.

  4. 12/2025 - 06/2026

    Microeconomics as physics

    Mahmut Osmanovic and Isac Paulsson completed their Master's research on modeling microeconomic processes as physical processes via reinforcement learning.
