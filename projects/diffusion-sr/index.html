About the project

What this project is about

Developing physics-informed temporal diffusion models as a data-enrichment method for symbolic regression.

This project focuses on one of the lab's newer scientific-ML directions: using diffusion models to generate physically consistent trajectories that improve symbolic-regression performance. The central idea is to enrich scarce or noisy measurements with synthetic samples that preserve governing dynamics, boundary conditions, or conservation structure. This makes the downstream symbolic model less brittle and more likely to recover compact equations from realistic data.
