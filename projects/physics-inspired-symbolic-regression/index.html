About the project

What this project is about

Advancing physics-informed symbolic regression for interpretable models discovered from data.

This project advances symbolic regression from a niche equation-search tool into a practical scientific machine-learning pipeline. The lab studies how to inject domain knowledge, distill strong black-box predictors into symbolic forms, and improve out-of-distribution robustness without sacrificing interpretability. The resulting systems are aimed at physics, engineering, and structured-data settings where researchers need both predictive performance and equations they can inspect.

Timeline

How the project developed.

  1. 03/2023

    Program launched

    The lab formalized its scientific-ML line around symbolic regression, interpretability, and physically grounded discovery.

  2. 2023-2024

    Framework and feature-engineering results

    Foundational work introduced domain-knowledge integration and symbolic regression as a feature-engineering layer for downstream models.

  3. 2025-2026

    Distillation and LLM-guided methods

    The project expanded to teacher-student distillation and large-language-model-based knowledge injection.
