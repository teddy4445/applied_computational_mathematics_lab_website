Simple math

A car, two numbers, and thousands of tiles

The engine is too weak to drive straight up the right-hand hill, so the agent must learn to swing back first. The state is the position x and the velocity v.

Dynamics
v ← v + 0.001 a − 0.0025 cos(3x)
x ← x + v, with a ∈ {−1, 0, +1}

Bounded to x ∈ [−1.2, 0.5] and |v| ≤ 0.07. The episode ends at x = 0.5; every step costs −1.

Tile coding
q(s, a) = Σ over active tiles of wᵢ

Each tiling cuts the (x, v) square into 8 × 8 tiles, shifted a little; exactly one tile per tiling is active, so the features are sparse.

Semi-gradient SARSA
w ← w + α (r + q(s′, a′) − q(s, a)) ∇q(s, a)

The gradient is 1 on the active tiles and 0 elsewhere, so each step changes only a few weights. Here α = (step-size numerator) / tilings.
